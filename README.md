# 吴晓波频道写作 Skill

一套中文财经商业写作技能，依据用户提供的71份样本研究笔记整理。它既保留吴晓波本人文章中的具体观察、阅读记忆和自我追问，也分别处理频道解释、新闻短评和商业内容的任务。

用于创作、改写与评审。它不是原作者身份代理，也不表示吴晓波或吴晓波频道参与、授权或背书。

## 内容

- [SKILL.md](wu-xiaobo-writing/SKILL.md)：技能入口与稿型选择。
- `wu-xiaobo-writing/agents/openai.yaml`：Codex显示名称及默认提示。
- `wu-xiaobo-writing/references/`：写作内核、作者区分、七类稿型、原创练习与评审。
- [样本索引](wu-xiaobo-writing/references/corpus-index.md)：71份样本的标题、署名、类型和分析链接。
- `wu-xiaobo-writing/references/studies/`：对应的71份历史研究笔记，按需读取。
- [试写任务](evals/cases.md)与[验证记录](evals/validation.md)：便于后续调整时复查。

两份巴黎合辑展开后共74篇文章条目；025、060、068仅按已提供部分研究。重复单篇没有额外计数。同一调查的不同短文不当作多次独立验证。

本包收录分析与方法，不附整篇新闻原文或第三方配图。原文章的政策、产品、行情与数字不是已核验知识，使用时需按任务重新核实。研究笔记的原文短引只用于分析；没有将第三方文章声明为本仓库拥有的作品。

## 使用

将完整的 `wu-xiaobo-writing` 文件夹放入所用工具的技能目录，保留内部相对路径。Codex通常使用用户目录下的 `.codex/skills/`；本仓库的“吴晓波”外层只是打包目录，技能目录名是 `wu-xiaobo-writing`。

示例：

```text
使用 $wu-xiaobo-writing，根据以下资料写一篇产业观察。
读者是制造业经营者，约1600字，不带营销。
```

```text
使用 $wu-xiaobo-writing，把这份采访整理成品牌新事。
目标是预约产品演示，保留功能与服务边界，不编客户成效。
```

```text
使用 $wu-xiaobo-writing，把我的真实参访笔记写成个人随笔。
保留我的身份和疑惑，不借用吴晓波的旅行或履历。
```

```text
使用 $wu-xiaobo-writing，评审下面这篇文章。
重点看标题是否兑现、因果是否成立、商业植入是否有具体价值。
```
