# v1.0 验证记录

日期：2026-10-28。

## 方法

以[六个虚构请求](cases.md)做独立试写。评估者读取技能和对应参考，不获取外部新闻；主任务逐篇检查实际输出。首轮发现问题后，仅修订有关指南，再对A、B、E三题复测。最终稿保存在[试写输出](outputs.md)。

检查的是稿型选择、材料边界、内容承诺和实际写法，未以匹配某个固定词句作为通过条件。

## 观察结果

| 任务 | 本次结果 |
| --- | --- |
| A 产业解释 | 从补能排队写到调度、经营账及异地推广条件；没有把等待减少直接换成能耗节省或产能增长。复测减少了反复解释“材料缺失”的写法。 |
| B 个人随笔 | 使用旧店址与刻度推进时间感，保留产品经理身份，没有添加采访、对话或父亲动机；复测以感受承接未知，减少自我审查式说明。 |
| C 课程推广 | 用四个经营问题说明课程用途，交代课次、时长和练习，保留试听行动；没有补造年资、学员数、效果及终身权益，排期与链接明确待定。 |
| D 金融短文 | 区分六人看好与赚钱概率，没有把未知的三人全部归为看空，没有沿用全仓指令或擅加直播日期。 |
| E 日日评 | 摘要和点评分开。复测正确使用收入与净利润，不从营收推销量；机器人演示、连续成功率和交付各有解释。 |
| F 采访整理 | 使用明确转述，给出可继续追问的问题，没有生成虚构回答或冒充原话，也没有把追踪方便扩写成已证实的回款改善。 |

## 已落实的修订

1. 首轮E把营收增长口语化为“卖得更多”，指标发生了变化。在日日评指南中补充收入、销量、价格与产品结构的区别；复测已修正。
2. 首轮B多次解释自己不能推测、不能编造，影响随笔自然度。在个人指南中明确以选材守住真实，把正文留给所见与感受；复测保留一次必要未知。
3. 首轮A频繁提醒材料不足。在解释稿指南中要求把未知放到影响结论的位置，通过缩小问题范围处理材料有限，不用限定语填充篇幅。
4. 在技能入口说明：写作规则不需要逐句讲给文章读者，虚构练习说明可以置于正文之外。

这是一次有限任务试写及三题复测，支持当前版本的可用性，不代表所有主题与长篇任务都已验证。品牌稿另有原创练习片段和样本对照，本轮未进行独立完整品牌成稿测试。新数据核验能力与真实营销效果不在本次验证范围。
