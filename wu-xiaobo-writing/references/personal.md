# 个人随笔与作者自述

主要依据028、039两份巴黎合辑，以及070课程自述，共六篇明确本人署名的独立文章。五篇来自同次旅行，不能视为完整生涯文风。先确认本次叙述者的真实身份和材料。

## 观察者要在文章里承受问题

旅行地点不是背景板。作者站在哪、看见哪个细节、为何突然想到一段旧事，决定思想的移动方式。香街上的门店位置有空间感，找不到的纪念牌让寻访转成自己的精神关系，旧书陪伴搬家让阅读有时间重量。

真正的个人转折是对象改变了观察者：看到新技术后，问题从“行业会怎样”变成“我的工作还有什么不可替代”。不要只站在高处解释别人，自己始终不付代价。

用户只有新闻材料时，可采用第三人称文化商业观察；只有“想写得有人味”也不足以编造一次参访。缺少关键个人经历时，先问发生过的一幕、一个真实想法，或直接交付不冒充亲历的版本。

## 常见推进方式，可择用

- 眼前一幕 → 阅读或历史记忆 → 原先理解遇到阻力 → 回到现在的自己。
- 寻找一个人或地方 → 没找到预期对象 → 想起自己为何在意 → 一个仍在发生的日常片刻。
- 两个同框的物件或标语 → 过去与现在 → 现场细节修正输赢叙事 → 保留复杂感受。

它们不是必经步骤。070的有效开篇反而是直说办学、招生与几个读者问题。

## 留下不必完成任务的细节

司机的闲谈可以突然聊足球，思想家的风衣可以只是好看，鸟停在路边不必象征命运。少量这样的细节让叙述不像观点机器。但不要人为分配“每篇一个俏皮句”，也不要继承原文对外貌的贬评。

“我以为理解了”“应该还是这样”可以标识认识边界，前提是来自真实感受。保留确实存在的矛盾，不急着把疲惫、徒劳或怀疑改写成励志结论。

真实性主要通过选材来守住。正文写实际看到的东西和自己的感受，不反复解释“我不能编造”“材料没有提供”“我无从知道”。确有意义的未知可以留一次，随后回到画面；不把随笔写成对自己的事实审核。读者需要认识这个人，而不只是看见他遵守规则。

典故应有私人关系或解释作用。列三个哲学家的名字不会自动产生文化厚度；若记不清引文，写自己的理解，不加引号冒充原话。

## 作者介绍自己的事业

070补充的路径：交代要做什么 → 真实经历如何形成方法 → 产品如何组织 → 读者获得什么 → 自己为什么愿意持续做。

履历按知识来源组织，而不是奖项堆叠。参与商业和观察商业可以有张力；承认不擅长的课题，才解释邀请其他老师的必要性。具体交付和精神意义可以同在，但前者不能被后者吞掉。

产品权益需精确：每年一次复听不等于无限次；学制、主课次数、专题课次数分别写。承诺“尽力持续”不等于客观保证永久运营。

## 收尾与评审

可回到出发时的物件、一个未解问题、自己的选择或审美偏好。也可清楚说明要做的事，不必总留白。不强行落到“中国赢了”“我们终将成功”。

评审时问：删去名人名言后，这还是一个具体的人吗？文中的经历是否属于本次叙述者？最后的感悟是否由前面的所见与变化产生？若只剩第一人称和漂亮哲理，重新找真实材料。
