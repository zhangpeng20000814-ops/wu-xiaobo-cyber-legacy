# 财经、产业与公司解释

## 先选本篇的推进动力

| 材料的主要张力 | 适合的组织方式 | 参照 |
| --- | --- | --- |
| 新设施改变路线和选择 | 场景 → 网络 → 企业行为 → 地区影响与条件 | 001 |
| 同一现象涉及不同利益 | 按角色解释成本、利益与行动，再呈现分化 | 052、069 |
| 一项解决方案带来下一项约束 | 运行场景 → 工程问题逐层解决 → 经营账 → 复制条件 | 065 |
| 股价或榜单变化与既有认知冲突 | 事件 → 经营与权力变化 → 反证或抵抗 → 后续验证 | 050、055 |
| 政策希望与实际执行有距离 | 文件改变什么 → 作用主体 → 落地关口 → 对人的影响 | 020、034、056 |
| 消费场景变成城市议题 | 具体使用 → 商业供给 → 公共服务 → 不同群体的需求 | 023、048、058 |
| 发布会热闹而商业问题未解 | 新品作为入口 → 用户价值 → 交付与成本 → 公司能力 | 027、047、071 |

不要把表格当七套固定目录。先选最有解释力的一条线，支线补必要信息即可。

## 开场要提供问题，不只提供热度

“市值跌了”之后问经营改善为何未带来相同定价；“退出外卖”之后核对究竟退出平台、折扣还是降低权重；“医保覆盖”之后追问报销的是设备购买还是训练服务。

强标题可以制造张力，正文要及时兑现，而不能靠不断换问题逃避回答。反常识只在确有材料时成立。

## 把采访和案例安排在需要它的位置

经营者说明怎样算账，技术人员解释为何难做，消费者呈现具体使用，研究者提供比较框架。相同观点不必请三位专家重复背书；分歧要保留各自条件。

案例要推动判断变化。069前半的小菜园说明渠道调整，后半再回访经营指标，使读者看到调整之后观察什么；仍不能单凭同期数据归因。031的正反案例也应接受同一标准，不能批评他人的数采中心后无条件赞美自己的例子。

053从非洲早期太空想象走向通信农业，再写不同国家的技术、市场与规则合作。规模叙事之外还要留下本地主体的选择，别把几十个国家写成一个人的单一意志。

## 技术要经历使用与经营的检验

参数 → 作用环节 → 使用者得到什么 → 在什么条件下成立。普通读者需要的不是术语数量，而是方案为什么这样设计。

047提供成功率、失败恢复和可复制性三种检验角度；它来源未明确，作为补充方法，不冒称频道典型作品。未披露某指标不代表没有能力。演示、实验基准、产品交付、稳定运营要分开。

065提醒：单机省电可能增加系统调度需求，局部改善不能替代总成本。056提醒：产品获批、技术准入、价格项目、编码、临床与经济评价、支付范围各自解决不同问题。只展开本题必要的环节。

## 用历史或理论时留住现实差异

思想解释可以先讲旧模型遇到的新困难，再介绍理论能回答什么，最后讨论局限（041）。公司分析则可在案例后用五力等框架整理行动（055），不要先列框架再把所有事实硬塞进去。

过去发生过类似故事，是比较的理由，不是必然重复的证据。成本、制度、需求与技术阶段不同，结果也可能不同。

## 结尾给读者可继续观察的东西

判断应回答谁的处境变了、哪项能力会更重要、下一步看什么证据。例如看真实复购、回款、单位成本、用户留存或服务执行，优于笼统说“未来可期”。

证据少时缩小文章的问题范围。不要用每段一句“材料没有提供”“目前不能判断”来撑篇幅；把关键未知集中到真正影响结论的位置，其余篇幅用于解释已知的过程。字数要求与材料不足冲突时，不能用虚构事实补齐。

也可以温和展望或回到生活场景。没有商业任务就不用插入课程和直播；出现品牌不等于广告，出现专家也不等于投资推荐。
