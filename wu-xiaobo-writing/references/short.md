# 短解释与直播转化

短文应减少本篇要回答的问题，保留使答案成立的条件。不要把长文删成一串更确定的结论。

## 按信息任务组织

| 要帮助读者完成什么 | 可选择的结构 | 样本 |
| --- | --- | --- |
| 理解一个冲击怎样传到自己 | 事件 → 关键传导环节 → 与读者有关的影响 | 040、054 |
| 比较不同行业处在什么阶段 | 同一比较标准 → 逐个差异 → 不可混同的信号 | 030 |
| 看懂地区与产业机会 | 按资源或任务分类 → 对应需求 → 读者如何继续观察 | 045、046 |
| 从日常现象看到经营变化 | 小场景与价格 → 分别解释驱动 → 更大问题 | 049 |
| 读一份专家调查 | 交代样本与问题 → 展示共识和分歧 → 界定用途 | 059、064、066 |
| 改正一个常见认知 | 读者困境 → 机制或错误 → 有条件的做法 | 009、013、024 |

不用把所有结构都写成“第一、第二、第三”。能用连续因果讲清，就连续讲。

## 从长文拆出短文

先选一个新的阅读任务，再选择材料。040与068高度相关，重点是油价对账户的传导或对生活成本的影响；059、064、066共同使用相近调查，分别回答资产观点、事件风险、资金功能。它们不是三次独立调查。

分清专家“看涨”、建议“高配”和资金配置比例。人数不能变成概率，若没有投票的完整分布，不补齐弃权或中立票。把调查意见写成专家观点，不变成给所有家庭的统一买卖指令。

政策短文尤其要保留法律层级与适用地域。057把地方探索压缩成全国用途、062把政策推演压缩为卖房窗口，是不能继承的跳跃；不要用文末“各地不同”“不构成建议”补救前面已经写实的断言。

## 写法与行动号召

开头尽快回答标题涉及的变化，再用少量最必要的数据。将术语翻译到本题用途即可，不展开整套教材。

直播预约是下一步，不是把已有答案扣到直播才能知道。本篇应独立完成承诺的解释，结尾说明直播会继续讨论哪个尚未展开或需要新信息的问题。

只有本次任务要求引流且给出活动信息时才写预约。样本中的10月19日、主讲人和主题都不是默认素材。没有日期和入口时，可先写不带具体排期的过渡或标明待补，不捏造。

## 文字压缩检查

删去一句后，因果还成立吗？去掉的是否恰好是样本范围、前提或反面证据？读者能否分清事实与建议？短债不能在删字时变成等同现金，高股息也不能变成不波动。只保留与本篇直接有关的提醒，不加通用风险长段。
